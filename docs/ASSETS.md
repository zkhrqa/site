# Комплект ассетов Альбома дружбы

Дата подготовки: 3 ноября 2026 года. Комплект предназначен для первой статической версии. Он хранится отдельно от будущего `web/`; публикация автоматически не выполняется. Подготовлены 11 PNG, 3 исходных TTF, 3 облегчённых WOFF2 и географическая основа с оригиналом. Полные источники, промпты, контрольные суммы, размеры и результаты проверки записаны в [assets/manifest.json](../assets/manifest.json) и `assets/metadata/`.

Статусы: `base` — подготовленный базовый актив для проверки в макете; `provisional` — временный образ, который может уточняться при выборе экрана; `planned` — отдельная работа ещё не выполнена. Статус `base` не означает, что пользователь уже утвердил каждое изображение.

Для первого экрана используется пустой музейный фон с отдельным cutout Егора; сюжетная сцена `egor-museum-v1.png` предназначена для истории ниже. Накладывать отдельного Егора на сюжетную сцену нельзя: это дублирует героя.

Карта v2 создана по отдельному layout 1400×680, полученному из достоверной географической проекции. Визуально проверены вид карты сверху, отдельные ёлки/берёзы, горные цепи, голубые речки, бурый медведь, олень, лиса, белый медведь и тигр; текста, UI и линии горизонта нет. Речка, рельеф и звери — символическая художественная графика, а не данные о руслах, высотах или ареалах. При реализации настоящий SVG clipPath ограничивает итоговый географический контур: генерированный край не служит географической основой.

Панорама — декоративный вымышленный пейзаж, а не сведения о расположении лесов, рек и гор. Она не содержит контура страны, границ, подписей, персонажей или интерфейса. При использовании внутри карты географический контур и проекция остаются отдельными достоверными данными.

Фактические пиксельные размеры могут отличаться от запрошенных — использовать проверенные значения manifest, не растягивать изображения ради соответствия этой таблице. Original PNG сохраняются; оптимизированные варианты при необходимости создаются отдельно на этапе сборки.

Бумага запрошена как бесшовная и очень малоконтрастная; повторение и читаемость на реальной странице ещё предстоит проверить. У шести отдельных cutouts и новой карты v2 проверена реальная альфа, а не нарисованный шахматный фон. Акварельные края содержат полупрозрачные пиксели. Отчёт — [image-validation.json](../assets/metadata/image-validation.json).

Генерированные изображения не объявляются автоматически CC0/MIT. Их происхождение — генерация Image Gen по собственному согласованному референсу этого проекта; сторонние лицензированные произведения в эти промпты не подставлялись. Применение регулируется соответствующими условиями сервиса, а референсы и промпты сохраняются как provenance.

Все три PNG имеют размер 1024×1536 и альфа-канал. Источники, промпты и контрольные суммы записаны в `assets/manifest.json`. Файлы v1 в таблице исходных ресурсов служат эталонами лица, позы и фактуры для дальнейших правок. Изображения представляют конкретные костюмы по предоставленным референсам. Культурный контекст раскрывает урок.

Для уроков 4–15 добавлены ещё 12 портретов в традиционной одежде. У каждого есть исходный PNG в `assets/illustrations/`, промпт со ссылками на музейные и этнографические источники в `assets/prompts/` и прозрачный WebP шириной 420 px. Контрольные суммы и результаты проверки альфа-канала внесены в манифест и отчёт.

Портрет Екатерины Ивановны Медведевой для главной предоставлен пользователем. Оптимизированная копия шириной 640 px хранится в `web/public/media/author-portrait.webp`. Кадрирование в овальной рамке сохраняет макушку и располагает лицо по центру.

## Что пока не готово и почему

| Материал | Статус | Что нужно для завершения |

| Публичное имя, должность, школа и контакты | Не подтверждены | Подтверждение автора; не подставлять сведения из метаданных документов автоматически |
| Айдар с младшей сестрой за столом, семейная книга | Planned | Принятый макет урока Айдара, размеры и согласованность с provisional-героем |
| Сцены Амины, культурные предметы, орнаменты | Planned | Состав экранов и проверенные культурные референсы |
| Сборка карты из географической основы и рисованной подложки v2 | Planned | Применить достоверный SVG clipPath, проверить совмещение с layout и политику границ; художественная подложка v2 уже готова |
| Места первых трёх знакомств | Не определены | Содержательное решение автора; это не случайные точки по рисунку |
| PDF уроков и DOCX вместо исходного DOC урока 2 | Planned | Отдельная подготовка и визуальная проверка Documents/PDF |

Для неизвестных следующих уроков активы не генерируются. Маркеры, фокус, кнопки и простые состояния реализуются семантическими элементами и согласованной библиотекой иконок; новый набор растровых пиктограмм для каждого состояния не нужен.

## Проверка комплекта

Проверены загрузки с HTTP-ошибками, сигнатуры TTF/WOFF2/ZIP/PNG, лицензии и номер версии Natural Earth, кириллица шрифтов, валидность GeoJSON, сохранение всех 7450 исходных пар координат и атрибутов выборки России, фактические размеры/режимы/альфа PNG и SHA-256 файлов. Визуально просмотрены результаты одиннадцати генераций. Музейная сцена проверена по образу Егора и двум референсам; на ней нет текста и элементов интерфейса. Пустой музейный фон проверен: окно слева, витрина с керамикой справа, свободный центр, без людей, лиц и надписей. Панорама проверена как отдельное непрозрачное изображение 2:1 без текста и географических границ. Оригиналы в каталоге generated_images сохранены; в проект скопированы отдельные PNG. Никакой художественной обработки изображений через Python не выполнялось. Браузерный, печатный и окончательный мобильный просмотр относятся к последующей реализации; сейчас они не заявляются выполненными.
