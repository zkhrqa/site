# Реализация первого маршрута и исправленной карты

## Что работает

React + TypeScript + Vite в `web/`, без регистрации, базы и прикладного API. Главная → карта неизвестных знакомств → карточка опубликованного урока → урок Егора → сборка послания → звезда на той же точке. `#/lesson/1/activity?projector` использует те же данные задания.

Главная кнопка ведёт к карте. Ни одна карточка не выбрана при первом входе и обновлении. 20 стабильных остановок: одна с опубликованным уроком, 19 с честным состоянием «Новое знакомство готовится». Анонимные будущие точки прямо разрешены пользователем; их размещение условно. Название «Альбом дружбы» остаётся рабочим и не означает двадцать отдельных карт.

## Файлы и добавление материалов

- `src/content/journey-stops.ts`: ID и условные координаты 20 остановок в пространстве 1400×680.
- `src/content/published-lessons.ts`: реестр опубликованных уроков, откуда карточка получает тему, героя и реальную ссылку.
- `src/JourneyMap.tsx`: одна постоянная карта, выбор, закрытие карточки, список, масштабирование, перемещение и группы.
- `src/features/map-layout.ts`: экранная группировка без потери остановок и границы перемещения.
- `src/features/progress.ts`: чтение, валидация, запись и перенос отметок. Допустимые ID берутся из реестра опубликованных уроков.
- `src/content/lesson-01.ts`: тексты и набор слов конкретного задания.

Для следующего урока сначала сверить материалы и сценарий, реализовать соответствующий маршрут, добавить его в реестр и связать существующую остановку с ID. Не создавать другую карту и не вставлять выдуманные сведения в ещё пустые остановки.

Карта загружается отдельными JS/CSS-чанками через React.lazy. Пока модуль загружается, показано короткое состояние загрузки. После загрузки якорь карты корректно позиционируется, восстановление прежней прокрутки не отправляет посетителя ниже карты.

Полная технологическая карта и лист доступны как отдельные DOCX. Их word/document.xml побайтово совпадает с исходниками; в публичных копиях очищены только creator/lastModifiedBy в docProps/core.xml. Не весь первый урок перенесён в интерактив; полный сценарий остаётся в печатных материалах. Неоднозначное сопоставление культурных объектов и остальные редакционные вопросы не опубликованы как проверяемые упражнения.

## Карта и графика

Путь вычислен из Natural Earth 1:50m v5.1.1 в проекции D3 с обработкой антимеридиана. Рисунок `russia-story-map-v2.png` создан Image Gen по географической основе и выбранному референсу; он ограничен настоящим путём через clipPath. Это отдельные акварельные леса, горы и звери, а не панорамный пейзаж. Рисунки декоративные и не претендуют на карту ареалов или физическую карту.

На большом экране видны 20 точек. В узком обзоре они группируются по экранному расстоянию; увеличение и список сохраняют доступ ко всем двадцати. У целей нажатия 48×48 CSS px вне зависимости от масштаба. Колесо не перехватывается, при увеличении доступны стрелки и перетаскивание. Книжная рамка на телефоне заменяется компактным окном той же карты.

## Прогресс

Ключ `album-druzhby:progress`, формат v1, опубликованный ID `lesson-01`. Только явное завершение ставит отметку; проверка задания её не блокирует. Отметка сохраняется после обновления в том же origin. Экспорт/импорт JSON объединяет отметки, проверяет 100 КБ, схему, версию и ID. Сбой storage не ломает урок и не выдаётся за успешное сохранение. Неподдерживаемое существующее сохранение не перезаписывается обычным завершением. Прежние данные можно заменить явным сбросом.

## Ограничения и выпуск

Готов один интерактивный фрагмент первого урока. Другие задания, уроки Айдара/Амины, PDF, сведения и фотография автора, брошюра и QR ещё предстоят. Проект не опубликован, GitHub push не выполнен. Для статического размещения в корне домена REG.RU используется содержимое `web/dist/client/`; hash-маршруты не требуют прикладного сервера. Перенос в подкаталог потребует настройки base/ссылок.
