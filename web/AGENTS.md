# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

Build app UI in `src/`. Keep `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs`, and `tests/sites-worker.test.mjs` intact so the same local prototype can be handed to Sites. Before a Sites handoff, run `npm run build` and `npm run test:sites`; the build must leave `dist/client/index.html`, `dist/server/index.js`, and `dist/.openai/hosting.json`.

## Мобильные уточнения, 3 ноября 2026

Шапка на телефоне закреплена при прокрутке; меню под кнопкой с тремя полосками раскрывается вертикально. Первый блок собирается в одну ширину: пояснение рядом с портретом, обе кнопки на всю ширину. Другие секции в рамках этой правки не перерабатываются.

## Плотность мобильного Hero, 3 ноября 2026

Пользователь одобрил оформление, но просит меньше пустоты между блоками первого экрана. Сохранять компактные промежутки между подзаголовком, автором, кнопками и подсказкой карты; не возвращать 180 px высоты авторской строки и крупные суммарные отступы. Содержание, настольная композиция и остальные секции сохраняются.

## Переходы, последнее решение 3 ноября 2026

Подсказка «Выберите урок на карте ниже ↓» удалена. Кнопки Hero плавно прокручивают страницу к нужному разделу; изменение адреса не должно прерывать плавную прокрутку мгновенным вторым переходом. Мобильное меню раскрывается и закрывается короткой CSS-анимацией transform/opacity, без анимации геометрии страницы и новых зависимостей. Обязательно учитывать prefers-reduced-motion.

## Каталог → подготовка → интерактив, 3 ноября 2026

Не возвращать дублирующий раздел «Продолжим знакомство». Каталог под картой содержит краткие сведения о героях и народах из документов; новые портреты и символика отложены пользователем. Готовая карточка ведёт на подготовку учителя: описание/цель, материалы, затем запуск интерактива. Будущие не ведут на пустые страницы. Остальные 17 героев и народов не выдумывать. Задание в интерактиве должно совпадать с конкретным заданием скачиваемого файла; не смешивать разные примеры технологической карты и рабочего листа.

## Весь рабочий лист, последнее решение 3 ноября 2026

Интерактив Егора — все задания 1–8 рабочего листа последовательно, с сохранением всех подпунктов и формулировок. Не возвращать сокращённый сценарий «история + задание 4». Работаем по одному персонажу. Любой развёрнутый ответ показывается как обсуждение в классе: без textarea и форм заполнения. Авторский ключ §5: сказки → предмет народного искусства; пословицы → народная мудрость и меткие выражения; матрёшка и Масленица → народные традиции и праздники. Порядок и экранные адаптации зафиксированы в docs/LESSON_01_WORKSHEET.md из корня.

В задании 1 нажатие выделяет слово заливкой и сплошным подчёркиванием ниже букв, повторное нажатие снимает выделение. Номер задания виден над заголовком. Светлая бумажная панель с мягкими скруглениями оставляет поля вокруг всех заданий и подсказок.

## Карточка и список на карте, 5 ноября 2026

Доступный урок обозначается сплошным зелёным знаком, готовящийся — светлым с пунктиром, пройденный — золотой звездой. Карточка урока открывается поверх карты по выбору точки и закрывается с возвратом фокуса. Каталог показывает четыре урока на телефоне и пять на более широком экране. Остальные плавно раскрываются, кнопка находится под всей сеткой. Примечание об условных координатах находится рядом с подсказкой карты. Меню и списки вариантов также раскрываются и сворачиваются плавно, с учётом `prefers-reduced-motion`. В проекторном режиме список вариантов меняет состояние сразу. Подробности карты — в `docs/MAP_REWORK.md` из корня.

В интерфейсе единица каталога и прогресса называется «урок», состояние завершения — «Урок пройден». В разделе «О проекте» и учебных текстах слово «знакомство» и его формы используются в обычном смысле ознакомления.

## Мобильное меню и переходы по главной, 5 ноября 2026

Меню компактно раскрывается под правой кнопкой. Действия первого экрана ведут к карте и описанию курса с первого нажатия, включая холодную загрузку карты. В описании проекта на телефоне заголовок идёт сразу перед текстом, без отдельной иллюстрации. На десктопе книга остаётся слева. Карточки уроков плавно появляются над картой, учитывая `prefers-reduced-motion`.

## Краткая подготовка к уроку, 6 ноября 2026

В первом блоке одна формулировка названия, строка «Урок 1» и сюжет. Ход урока описан двумя абзацами. Технологическая карта и рабочий лист скачиваются отдельными строками с названием, описанием и форматом DOCX. Переход в интерактив находится под ними.
