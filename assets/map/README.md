# Географическая основа России

Источник: Natural Earth, Admin 0 — Countries, масштаб 1:50m, версия 5.1.1.

- Страница набора: https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/
- Официальный ZIP: https://naturalearth.s3.amazonaws.com/50m_cultural/ne_50m_admin_0_countries.zip
- Условия использования: https://www.naturalearthdata.com/about/terms-of-use/
- Дата скачивания: 2026-11-03.

## Состав

`original/ne_50m_admin_0_countries.zip` — неизменённый официальный архив.

`original/ne_50m_admin_0_countries/` — полный распакованный shapefile со всеми странами, исходными атрибутами, README, проекцией и номером версии.

`original/natural-earth-terms-of-use.html` — сохранённая страница условий использования.

`derived/russia-natural-earth-50m.geojson` — один объект `ADM0_A3=RUS`, выбранный из исходного набора. Сохранены все координаты и исходные атрибуты. Упрощение, проекция, художественная обработка и редактирование границ не выполнялись. Скрипт воспроизведения — `extract-russia.py` (Python + pyshp).

## Ограничения основы

По описанию издателя, границы по умолчанию отражают de facto status. Это выбранный издателем картографический набор, а не самостоятельно проверенная юридическая схема границ или карта расселения народов. Перед публичным выпуском необходимо определить редакционную политику карты; не изменять спорные границы без подтверждённого источника и осознанного решения.

Геометрия — `MultiPolygon`, 7450 пар координат WGS84, включая части по обе стороны 180-го меридиана. При отображении России нужно корректно обрабатывать антимеридиан и выбирать подходящую проекцию. Наивное растягивание диапазона от −180° до +180° даст неудачную композицию.

Это географическая основа для реализации интерактивной карты, а не готовая акварельная картинка. Издательский масштаб 1:50m подходит для обзорного контура, не для точного определения локальных границ, населённых пунктов или территорий проживания.
